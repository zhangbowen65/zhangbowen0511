不写代码，写提示词：两轮迭代驯服 AI

目标：把「无缝循环 / 3.2 秒自动翻页且手动后不停 / 圆点分页器可点 / 初始 cube」四条需求翻译给 AI，让它生成 new Swiper('#wySw4', {...}) 配置。硬性要求：至少迭代 2 轮，保留每轮提示词与回答。

第 1 轮 · 随意提问（埋坑实录）

💬 第 1 轮提示词

帮我生成一段 new Swiper('#wySw4', {}) 的配置代码，要求开启无缝循环、自动轮播 3.2 秒一次、带可点击圆点分页器，初始效果是 cube。

🤖 第 1 轮 AI 回答（模拟典型输出）

{
  loop: true,
  autoplay: { delay: 3.2, disableOnInteraction: true },
  pagination: { clickable: true },
  effect: 'cube'
}
问题错在哪正确写法
① 单位错delay: 3.2 —— delay 单位是毫秒，3.2 毫秒等于没停delay: 3200
② 拖动就停disableOnInteraction: true 是默认值，用户一拖自动播放永久停止disableOnInteraction: false
③ 分页器没通电漏了 el，圆点元素 #wyPag4 没绑上，页面上不显示el: '#wyPag4'
④ 选择器照抄题目给的 #wysw4 大小写有坑，页面真实 id 是 #wySw4#wySw4

第 2 轮 · 补上下文再问（一次到位）

💬 第 2 轮提示词

重新生成 new Swiper('#wySw4', {}) 的完整配置对象，严格遵守全部 4 条规则：① 开启无缝循环 loop；② 自动轮播间隔 3200ms（单位毫秒），重点：用户手动滑动、点击分页器之后自动轮播不能停止，autoplay 必须设置 disableOnInteraction: false；③ 分页器是圆点，el 绑定 #wyPag4（页面演示四的真实 id），开启 clickable: true 支持点击跳转；④ 切换特效 effect: 'cube'。只输出配置花括号内部内容。

🤖 第 2 轮 AI 回答（最终采纳）

{
  loop: true,
  speed: 800,
  effect: 'cube',
  autoplay: {
    delay: 3200,
    disableOnInteraction: false
  },
  pagination: {
    el: '#wyPag4',
    clickable: true
  }
}

✓ 四条需求全部命中，可直接粘进 swiper-task.html 演示四的初始化里验证。
