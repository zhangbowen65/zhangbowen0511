第 7 种效果：creative 电影选片墙

课堂只讲了 6 种 effect，第 7 种 creative 是完全自定义变换：滑动时上一张缩小、左移、带角度，像退到侧墙上的旧海报；下一张放大、右移进场，像新海报翻出来成为主角。

核心代码：creativeEffect 的 prev / next 变换

选片墙的关键是给退场/进场的海报各配一套 translate + rotate + scale：绕 Y 轴旋转（rotateY）让侧边海报像贴在墙上、朝向观众，Z 轴后退（translate 第三项）制造纵深，电影感由此而来。

var zbw511_wall = new Swiper('#zbw511_wall', {
  loop: true,
  effect: 'creative',
  speed: 800,
  autoplay: { delay: 3200, disableOnInteraction: false },
  pagination: { el: '.swiper-pagination', clickable: true },
  creativeEffect: {
    limitProgress: 2,                        // 允许左右各看到 1 张海报，形成"墙"的层次
    shadowProgressPerSlide: 1,               // 投影随进度加深，海报像浮出墙面
    prev: {    // 上一张：退到左边墙上
      translate: ['-108%', 0, -300], // 左移 108%、向屏幕深处退 300px
      rotate: [0, 38, 0],           // 绕 Y 轴转 38°：海报侧贴在墙上、面向观众
      scale: 0.68,                  // 缩到 68%，远处的海报更小
      opacity: 0.5,                 // 变暗，退为背景
      shadow: true                  // 带投影，立体感
    },
    next: {    // 下一张：从右边进场
      translate: ['112%', 0, -180],  // 从右侧 112% 处、带一点纵深滑入
      rotate: [0, -28, 0],           // 进场时反向内倾 28°，滑到中间转正面向观众
      scale: 1.06,                  // 放大 6%，"翻出来"的冲击感
      opacity: 1
    }
  }
});

通俗回答：prev 和 next 的 transform 分别控制什么？

🧾 prev —— 控制"已经翻过去的那张"怎么摆姿势

它决定旧海报退场后的站位：挪到哪（左移 108%）、退多远（向屏幕深处 300px）、歪多少度（绕 Y 轴 38°）、缩多小（68% 倍）。在电影墙里就是让它像一张看完的海报，贴到左边墙上、侧身朝向观众、缩小变暗退为背景。

🎬 next —— 控制"马上要进来的那张"从哪登场

它决定新海报的进场姿态：从右边 112% 的位置滑入、带反向内倾角度（-28°）像被翻出来、放大 6% 增加冲击力，滑到正中间时完全转正、铺满画面成为主角。

一句话总结：prev 管"退场的怎么退"，next 管"进场的怎么进"，Swiper 负责在两者之间做平滑过渡——两个变换的差值越大，过渡的"戏剧感"越强。
